# scripts-safe

Безопасный набор скриптов, отобранных из `/home/boris/script` для git-репозитория.

## Что внутри

- `safe/` - скрипты, которые можно хранить в git без найденных жёстко зашитых секретов
- `manifests/` - индекс исходных скриптов из большой папки `/home/boris/script`

## Почему не весь /home/boris/script

Исходная папка содержит:

- старые одноразовые утилиты;
- архивы, xlsx, бинарники;
- в ряде файлов найдены пароли, токены и чувствительные данные.

Поэтому в этот репозиторий попадают только проверенные и относительно чистые утилиты.

- `safe/ac_modbus_gui.py`
- `safe/iptables_gui.py`
